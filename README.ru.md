# SendFlow

[English](README.md)

Массовая рассылка сообщений в WhatsApp через веб-интерфейс. Добавляете контакты, пишете сообщение — отправляете.

## Перед использованием

Вы должны быть авторизованы в [WhatsApp Web](https://web.whatsapp.com) в 기본ном браузере. При запуске SendFlow автоматически открывает WhatsApp Web, чтобы тот успел загрузиться.

## Установка

```bash
pip install -r requirements.txt
```

Рекомендуется Python 3.12+.

## Запуск

```bash
python app.py
```

Откроются две вкладки:
1. `web.whatsapp.com` — отсканируйте QR-код, если ещё не вошли
2. `localhost:5000` — интерфейс SendFlow

## Как работает

1. Добавляете контакты (номер телефона + сообщение)
2. Выбираете: отправить сейчас или запланировать на время
3. Нажимаете **Отправить**
4. PyWhatKit поочерёдно открывает вкладки WhatsApp Web для каждого контакта и отправляет сообщение
5. Статус обновляется в реальном времени: ожидание → отправка → отправлено/ошибка

## Возможности

- Отправка нескольким контактам по очереди
- Планирование на конкретное время (24-часовой формат)
- Быстрая отправка
- Остановка и сброс во время рассылки
- Статус в реальном времени с уведомлениями
- Тёмная и светлая тема
- Интерфейс на русском и английском

## Стек

- **Бэкенд:** Flask
- **Автоматизация WhatsApp:** PyWhatKit
- **Фронтенд:** vanilla HTML/CSS/JS (без сборки)

## Примечания

- PyWhatKit использует сессию WhatsApp Web из вашего браузера — никаких ключей API не нужно
- Сообщения отправляются поочерёдно с небольшой задержкой
- Номера телефонов указывайте с кодом страны (например `+79991234567`)
